exquisite corpse, hand-drawn pass

Your marker sketch, traced into vectors and dropped into the four screens of the app. Every outline shape (buttons, frames, swatch circles, outline pencils) is a stroked path, so one line-weight number controls all of them at once. The solid pencils and fill icons are traced as filled shapes and keep the weight you drew.

Scroll each row sideways. The first phone in each row is the app as it ships today. Below the rows there is a mixer to combine any pieces you like.

Recommended combo

My pick after looking at how the app behaves today. Buttons: family A, stretched a little. It is the wider family, so it needs the least distortion to fit the current button sizes, the tools area stays as short as it is now, and "done" turning into "sure?" still fits. Frames: frameL3 on the canvas, frameP3 on the reveal. The frame traces are pulled halfway toward a true rectangle, so they stay hand-drawn but the drawing area never crosses the line; each frame sits outside the box by however far its line still bows inward. Swatches: each color is filled into its own uneven circle from the sheet, no outline. The selected one gets an outline of the same shape hugging its edge, with a hairline gap so it reads on black too. That keeps the current "ring means selected" behavior and it works on black and white. The white swatch keeps a faint grey edge so it stays visible. Pencils: the solid ones, since the fill icon only exists solid; the tool row stays one weight. Undo: a hand-drawn arrow at the right end of the tool row, so the row is five wide and lines up under the five swatch columns; done sits alone below. Buttons are pulled 40% toward a true rectangle so they read a little calmer than the raw trace. Tool boxes: only the selected tool gets a box, drawn with a frame glyph. Colors get circles, tools get squares. Pass screen: the vertical squiggle stays, it is the brand mark; only the button changes. Line weight 2.5px. Swatch circles are pulled 20% toward a true circle, with any bulge past 8% of the mean radius soft-clamped, and each fills the same square, so they read as one set without losing the hand.
