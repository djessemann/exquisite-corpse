# Exquisite Corpse

A pass-and-play drawing game. The web version is `index.html` at the repo root, published via GitHub Pages as a PWA. The iOS version is a native SwiftUI app in `ios/`.

## iOS work

If the task involves iOS, Xcode, the App Store, or the `ios/` folder:

1. Read `docs/ios-app-plan.md`. Part 2 is your instructions.
2. Read `docs/ux-spec.md`. It is the contract for what the app does.

The iOS app is native Swift. No web view, no JavaScript, no dependencies. Match the web app's experience, not its code. When the spec and `index.html` disagree, `index.html` wins.
