# Exquisite Corpse

A pass-and-play drawing game. The whole app is `index.html` at the repo root, published via GitHub Pages as a PWA.

## iOS work

If the task involves iOS, Xcode, the App Store, or the `ios/` folder, read `docs/ios-app-plan.md` first. Part 2 of that doc is your instructions. Follow it.

Never fork a separate copy of `index.html` for iOS. The root file is the single source of truth.
